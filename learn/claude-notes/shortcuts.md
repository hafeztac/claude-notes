#   Keyboard shortcuts

## Shortcuts
`Shift+Tab`         cycles between `auto`, `manual`, `acceptEdits` and `plan` modes.
`Ctrl+b`            backgrounds running agents and bash commands.
`Ctrl+x, Ctrl+k`    kill all background agents.
`Ctrl+y`            restore cleared buffer.
`Ctrl+l`            re-draw screen and clear prompt input.
`Ctrl+o`            toggle transcript viewer
`[`                 dumps transcript to scrollback; give
`v`                 dumps transcript into nvim
`Ctrl+r`            search through command history. `Ctrl+s` cycles through search target between: {session history, project history, all history}
`UpArrow`           Previous prompt
`DownArrow`         Next prompt
